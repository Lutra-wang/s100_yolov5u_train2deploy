> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the official OE + Model Zoo YOLOv5u path with an independently reproducible 128-image dataset and measured S100 metrics.

**Architecture:** Preserve Model Zoo scripts as the inference, conversion, and deployment implementation. Put data selection and result-format bridging in isolated helper scripts, retaining source artifacts and logs for every stage.

**Tech Stack:** WSL, Conda Python, Ultralytics YOLOv5u, Horizon OE/Model Zoo, S100 HBRT, COCO API.

**Spec:** `docs/superpowers/specs/2026-09-15-coco2017-val128-s100-design.md`

## Global Constraints

- Do not reuse any old dataset-specific model, ONNX, calibration, HBM, board output, or metric as a new result.
- Prefer OE and Model Zoo supplied scripts; document each required custom helper and its narrow purpose.
- Archive before deleting; validate archive manifest and hashes before deletion.
- Use fixed source URLs, fixed image IDs, and an explicit split so the manual works from a clean host.
- Evaluate identical test images with COCOeval `bbox` AP@[.50:.95] and report all/small/medium/large for FP32 and BPU Python.
