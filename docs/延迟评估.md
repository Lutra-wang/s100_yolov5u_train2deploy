# 延迟评估：S100 HBM

## 结果

模型为 `yolov5nu_coco2017_val128_s100_nashe_640x640_nv12.hbm`，S100 `nash-e`，工具为板端官方 `hrt_model_exec perf`，每项 200 帧。

| 线程数 | 平均 BPU 任务延迟 | 吞吐 |
|---:|---:|---:|
| 1 | 1.233 ms | 794.452 FPS |
| 2 | 1.867 ms / 线程 | 1053.081 FPS |

## 口径与证据

执行命令：

```bash
hrt_model_exec perf --thread_num 1 --model_file yolov5nu_coco2017_val128_s100_nashe_640x640_nv12.hbm
hrt_model_exec perf --thread_num 2 --model_file yolov5nu_coco2017_val128_s100_nashe_640x640_nv12.hbm
```

原始日志和 `model_info.log` 均为本地生成的板端输出，未纳入 Git。模型 I/O 已由本地 `model_info.log` 复核：NV12 双输入 `images_y`/`images_uv`，640×640。

该 `perf` 命令测量从提交 BPU 任务到等待完成的运行时基准，不含读取图片、NV12 构造、Python 后处理或网络传输；不应表述为完整端到端业务延迟。
