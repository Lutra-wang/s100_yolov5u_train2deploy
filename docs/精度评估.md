# 当前项目量化评估参数

本文件只记录本项目自训练 YOLOv5nu 的量化前后实测参数，供与 Model Zoo 官网同模型参数自行比较；不包含官网模型的二次对照结论。

## 模型与评估条件

- FP32：`train/runs/coco2017_val128_s100-2/weights/best.pt`。
- BPU：`conversion/output/yolov5nu_coco2017_val128_s100_nashe_640x640_nv12.hbm`，S100 官方 `Ultralytics_YOLO_Detect` Python 运行时。
- 图像：固定 16 张 `coco2017_val128_s100` 测试图；640×640、score threshold 0.25、NMS IoU 0.7。
- 指标：未修改 `pycocotools`，`iouType=bbox`。`mAP50-90` 为 IoU 0.50 至 0.90、步长 0.05 的 AP 均值。

## 量化前后精度

| 参数 | FP32 | BPU Python | 差值（BPU - FP32） |
|---|---:|---:|---:|
| mAP50 | 0.388 | 0.414 | +0.026 |
| mAP50-90 | 0.292 | 0.321 | +0.029 |
| mAP50-95 | 0.266 | 0.293 | +0.027 |

小样本下 BPU 数值略高是实际输出结果；不应解读为量化必然提升精度。使用官网完整 COCO2017 指标时，应以相同的 5,000 图评测配置再验证。
